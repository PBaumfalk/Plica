# 7 · Export und PDF

## Export

**CSV** (UTF-8, für Excel vorbereitet) und **XLSX** – für alle Antworten, die aktuelle Filterung oder eine Auswahl. Inhalte, die mit `=`, `+`, `-` oder `@` beginnen, werden entschärft, damit Tabellenprogramme sie nicht als Formel ausführen. Exporte werden im Protokoll vermerkt.

## PDF je Antwort

Jede Antwort lässt sich als gestaltetes PDF herunterladen: Formulartitel, Nummer, Eingangszeit, Version, alle Angaben in Formularreihenfolge, Unterschriften und eine Fußzeile mit Seitenzahl und Antwort-ID.

## PDF-Vorlage

Unter **PDF-Vorlage** gestalten Sie ein eigenes Dokument mit Platzhaltern aus den Formularfeldern (`{{name}}`, `{{anschrift}}` …) und sehen sofort eine Vorschau mit echten Daten. Das PDF kann auch eine [Automation](08-automationen.md) erzeugen.
