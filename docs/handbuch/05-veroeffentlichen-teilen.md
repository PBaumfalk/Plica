# 5 · Veröffentlichen und Teilen

**Veröffentlichen** im Editor prüft das Formular und erzeugt eine neue Version. Unter **Teilen** finden Sie:

- **Link** zum Kopieren und eine frei wählbare Adresse (`/f/kontakt`),
- **QR-Code** zum Herunterladen,
- **Einbettung** in Ihre Website per iframe, wahlweise mit automatischer Höhenanpassung,
- **Zugang**: Passwortschutz, Zeitraum (geöffnet ab / Antworten bis), Höchstzahl an Antworten,
- **Benachrichtigung** an E-Mail-Adressen bei jeder neuen Antwort,
- **Aufbewahrung**: Antworten nach X Tagen automatisch löschen,
- **Pausieren, Archivieren, wieder öffnen**.

## Nach dem Absenden

Unter **Abschlussseiten** legen Sie fest, was Absendende sehen – auch mehrere Varianten, gesteuert über Regeln – oder leiten auf eine eigene Seite weiter.

## Fortsetzen und Folgeformulare

- Ist **Später fortsetzen** aktiviert, erhalten Ausfüllende einen privaten Link, über den sie einen Zwischenstand später wieder öffnen. Zwischenstände werden verschlüsselt gespeichert und laufen ab.
- Aus einer Antwort heraus können Sie ein **Folgeformular** mit vorausgefüllten Angaben verschicken.
- Versteckte Felder übernehmen Werte aus dem Link, z. B. `?quelle=newsletter`.

## Spam-Schutz

Jedes öffentliche Formular hat ein unsichtbares Honeypot-Feld, verlangt eine realistische Mindest-Ausfüllzeit (2,5 Sekunden) und begrenzt Einreichungen je Absender. Füllt ein Bot das Honeypot-Feld aus, wird die Einreichung still verworfen. Wer schneller als die Mindestzeit absendet, erhält dagegen einen Hinweis und kann einfach erneut senden – so gehen Angaben echter Menschen nie unbemerkt verloren.
