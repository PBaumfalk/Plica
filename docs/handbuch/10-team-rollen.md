# 10 · Team und Rollen

Unter **Einstellungen → Team** laden Sie Personen per Link (auf Wunsch zusätzlich per E-Mail) ein und vergeben Rollen.

| Recht | Leser | Prüfer | Bearbeiter | Administrator | Inhaber |
|---|:-:|:-:|:-:|:-:|:-:|
| Formulare und Antworten ansehen | ✓ | ✓ | ✓ | ✓ | ✓ |
| Antworten bearbeiten (Status, Tags, Notizen), Freigaben entscheiden | | ✓ | ✓ | ✓ | ✓ |
| Formulare bauen, veröffentlichen, Automationen, Export | | | ✓ | ✓ | ✓ |
| Formulare und Antworten löschen, Mitglieder, Einstellungen, API-Schlüssel, Protokoll | | | | ✓ | ✓ |
| Workspace löschen, Inhaberschaft übertragen | | | | | ✓ |

Administratoren können niemanden zum Administrator oder Inhaber machen. Alle Rechte werden auf dem Server geprüft; ausgeblendete Schaltflächen sind nur Komfort.

## Konto und Sicherheit

Unter **Einstellungen → Konto**: Name, Passwort (mindestens 10 Zeichen), **Zwei-Faktor-Anmeldung** mit einer Authenticator-App (TOTP) und einmaligen Wiederherstellungscodes, sowie die Liste aktiver Sitzungen mit Abmelden einzelner Geräte. Nach fünf Fehlversuchen wird die Anmeldung zunehmend verzögert.
